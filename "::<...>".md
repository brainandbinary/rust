
The expression `.collect::<Vec<_>>()` in Rust is used to **collect items from an iterator into a vector (`Vec`)**. Let’s break it down:

---

### 🔍 `.collect()`

`collect()` is a method provided by the **Iterator** trait in Rust. It consumes the iterator and **gathers all the yielded values** into a collection like:

* `Vec<T>` (vector)
* `String`
* `HashMap<K, V>`
* `HashSet<T>`
* Custom collections (if they implement `FromIterator`)

---

### 🧠 But why `::<Vec<_>>`?

This is **type annotation using turbofish syntax** (`::<...>`), telling Rust *what kind of collection* you want.

* `Vec<_>` means: collect into a vector of **inferred type**.
* The `_` lets the compiler figure out the element type automatically.

---

### ✅ Example: Collecting numbers into a Vec

```rust
let nums = [1, 2, 3];
let vec = nums.iter().map(|x| x * 2).collect::<Vec<_>>();
// vec = [2, 4, 6]
```

Here:

* `nums.iter()` → creates iterator over `&i32`
* `map(|x| x * 2)` → transforms each element (still type: `i32`)
* `collect::<Vec<_>>()` → gathers the result into a `Vec<i32>`

Rust infers `_` to be `i32`, so it becomes `Vec<i32>`.

---

### 🆚 What if you omit the type?

If the type isn’t obvious from context, Rust gives a **type inference error**:

```rust
let result = some_iterator.collect(); // ❌ Error: type annotation needed
```

That’s why we often write:

```rust
let result: Vec<_> = some_iterator.collect();
```

or

```rust
let result = some_iterator.collect::<Vec<_>>();
```

Both are the same.

---

### ✅ Summary:

| Part         | Meaning                                     |
| ------------ | ------------------------------------------- |
| `.collect()` | Gather items from an iterator               |
| `::<Vec<_>>` | Specify the target collection type (vector) |
| `_`          | Let the compiler infer the element type     |

Absolutely! Here are several **clear examples** of using `.collect::<T>()` in Rust, collecting iterator results into various types.

---

## 🧵 1. Collect into a `Vec<T>` (most common)

```rust
fn main() {
    let squares = (1..=5).map(|x| x * x).collect::<Vec<_>>();
    println!("{:?}", squares); // Output: [1, 4, 9, 16, 25]
}
```

* `(1..=5)` creates an iterator from 1 to 5
* `.map(|x| x * x)` squares each number
* `.collect::<Vec<_>>()` gathers them into a `Vec<i32>`

---

## 🔡 2. Collect into a `String`

```rust
fn main() {
    let chars = ['R', 'u', 's', 't'];
    let result = chars.iter().collect::<String>();
    println!("{}", result); // Output: "Rust"
}
```

* Each char gets collected into a `String`
* Works because `String` implements `FromIterator<char>`

---

## 🗺️ 3. Collect into a `HashMap<K, V>`

```rust
use std::collections::HashMap;

fn main() {
    let data = vec![("apple", 3), ("banana", 2), ("orange", 5)];
    let map = data.into_iter().collect::<HashMap<_, _>>();

    println!("{:?}", map); // Output: {"apple": 3, "banana": 2, "orange": 5}
}
```

* `vec![(K, V)]` is turned into a `HashMap<K, V>`

---

## ✅ 4. Collect into a `HashSet<T>`

```rust
use std::collections::HashSet;

fn main() {
    let nums = vec![1, 2, 3, 2, 1, 4];
    let set = nums.into_iter().collect::<HashSet<_>>();
    println!("{:?}", set); // Output: {1, 2, 3, 4}
}
```

* Duplicates are removed automatically

---

## 🧮 5. Collect with filtering

```rust
fn main() {
    let nums = 1..=10;
    let evens = nums.filter(|x| x % 2 == 0).collect::<Vec<_>>();
    println!("{:?}", evens); // Output: [2, 4, 6, 8, 10]
}
```

* Combines `.filter()` with `.collect()`

---

## 🧠 Tip: Without turbofish

You can also use type inference:

```rust
let evens: Vec<_> = (1..=10).filter(|x| x % 2 == 0).collect();
```
